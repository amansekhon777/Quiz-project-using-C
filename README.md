
# 🎯 C Quiz Game

A beginner-friendly command-line quiz game built using **C programming**. Test your knowledge of basic C concepts by answering 10 multiple-choice questions and tracking your score!

## 📌 About the Project

This is my first C programming project as I begin my coding journey as a B.Tech Computer Science Engineering student specializing in Artificial Intelligence and Machine Learning.

The quiz covers fundamental programming concepts, including variables, format specifiers, operators, loops, arrays, pointers, and functions.

## ✨ Features

- 10 multiple-choice questions about C programming
- Four options for each question (A, B, C, D)
- Automatic answer checking
- Live score tracking
- Final score and percentage calculation
- Performance feedback based on your score
- Input validation for quiz answers
- Option to play the quiz again
- Support for uppercase and lowercase answers

## 🛠️ Technologies Used

- **Language:** C
- **Standard Libraries:** `stdio.h`, `ctype.h`
- **Compiler:** GCC or another C99-compatible compiler

## 🚀 How to Run

### 1. Clone the repository

```bash
git clone https://github.com/YOUR_GITHUB_USERNAME/c-quiz-game.git
```

### 2. Open the project folder

```bash
cd c-quiz-game
```

### 3. Compile the program

Using GCC:

```bash
gcc -std=c99 -Wall -Wextra -pedantic main.c -o c-quiz-game
```

### 4. Run the quiz

**Linux / macOS:**

```bash
./c-quiz-game
```

**Windows:**

```bash
c-quiz-game.exe
```

## 🎮 How to Play

1. Run the program.
2. Read each question and its four options.
3. Enter `A`, `B`, `C`, or `D`.
4. Get immediate feedback on your answer.
5. View your final score and percentage.
6. Enter `Y` to play again or `N` to exit.

Each correct answer earns 1 point. There is no negative marking.
